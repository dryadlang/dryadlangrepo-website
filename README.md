# Dryad Programming Language Website

Official documentation, blog, and specifications for the Dryad Programming Language.

Built with [Astro](https://astro.build) + React islands for interactive components.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in `.env.local` to your Gemini API key (if needed)
3. Start the dev server:
   `npm run dev`

## Build & Preview

- `npm run build` — builds the static site to `dist/`
- `npm run preview` — previews the built site locally
